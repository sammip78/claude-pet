# /pet

A tiny pixel you that sits above the prompt in Claude Code and reacts while Claude works. It thinks along with Claude, sweats when tests fail and cheers up when they pass or a push goes through.

Made by Sam Biradar.

## Install

At the prompt of a terminal session:

```
/plugin install pet --marketplace sammip78/claude-pet
```

From a shell:

```bash
claude plugin install pet --marketplace sammip78/claude-pet
```

In the desktop app, click + next to the prompt box, then Plugins, Add marketplace with `sammip78/claude-pet`, then Add plugin.

## Use

Everyone starts with the default pet. Run `/pet` with a photo of yourself and Claude draws your own, which then shows in every chat.

`/pet quiet` turns its comments off and `/pet talk` turns them back on.
